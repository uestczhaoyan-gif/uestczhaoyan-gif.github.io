# 基于斯多葛主义的博士初期人生思考

## 1. 关于思维

**自我批评：**

自正式升入博士阶段以来，我时常会暗自神伤，对保研时做出的决定懊悔不已。我总觉得自己本该去尝试更好的平台，但时至今日已无力挽回。现在回想，当时做出的那个如今看来不算正确的选择，主要归咎于两点。

一方面是我缺乏对自己的清醒认知，过度高估了自己的精神境界：虽然内心渴望平静稳定的生活，但年少轻狂让我依然有股“争天争地”的冲动，加上社交媒体上同辈带来的无形比较与压力，都让我在即便选择了保守路径后，也无法真正安稳度日。另一方面，我长久以来的“保守倾向”让我在面对重大抉择时极其怕麻烦。我不愿意去做广泛、细致的调研，而是倾向于凭第一直觉做决定；一旦内心有了某个偏好，我甚至会自圆其说地编造一个“谎言”来说服自己，最终草率、随性地定下未来。也许，我并非完全因为没去更高的平台而懊悔。最大的悲哀其实在于：没有尝试、没有经历失败，就先一步自我放弃了。但归根结底，这一切都是自己造成的，不该去埋怨别人。

在“知行合一”方面，我做得并不好。我习惯于把事情想得很长远、规划得极度细致，试图把方方面面都囊括其中。比如，我会制定博士阶段的长、中、短期乃至每日规划，又总在偶尔萌生新想法时不断往里添加，导致计划越来越臃肿，难以落地。而在执行时，我又非常依赖“极简方案”，全凭当天的状态和精力行事。于是，我陷入了一个死循环：**想很多 -> 尝试做 -> 事情太多无从下手 -> 低效行动 -> 焦虑反思继续想**。每天我都要花大量时间和精力去和自己“和解”，这严重拖累了我的工作效率和精神状态。

**如何改正：**

所谓“君子当有龙蛇之变”，无论身处何地、遭遇什么，都要相信自己，对个人的人生负责。人生没有定论，改变随时都不晚。我要做的是直面过去的缺陷，勇于挑战，越是抵触的事情，越要放手去试。

斯多葛主义的两个核心观点给了我很大启发。其一是“宿命论”（接受命运）：既然过去的事情已经发生，那就是命中注定，不可更改，我们只能从中汲取教训，而非沉溺于懊悔。其二是“控制三分法”：世间的事分为我们能控制的、能部分控制的，以及完全不能控制的。做事时，我们只需倾尽全力去掌控自己能控制的部分。比如准备面试，你能控制的是知识储备和状态调整；你不能控制的是 PPT 版本过旧导致 SVG 图片无法显示（是的，我遇到过这种惨剧），或者是面试官的心情及最终结果。既然无法控制，就没必要为此黯然神伤；即使失败，只要做到于己问心无愧即可。

因此，在这个充满繁杂琐事的博士阶段，我的核心任务其实很简单——做一个不被设限的研究者。我要充分发挥对各个学科领域的好奇心，全方位发展，努力成为一个越来越接近真相与真理的人。我不能再让繁琐的长期计划束缚自己。每天当然要有分场合、分精力的基础任务安排，但绝不能再把一拍脑门想到的点子强行塞进任务列表，徒增负担。

真正的成长应该是一种“自然涌现”。在每天努力认知世界、创造价值的过程中，实习、论文、竞赛都会基于我的能力和当下的需求顺理成章地发生。我每天需要记住的只有一点：**让思维野蛮生长**。在 AI、Optics & Photonics、Hardware、Material 等领域充分发散思维，借助 AI 的力量让想法落地生根。这既是能力的锻炼，也是实质的项目产出。同时，必须坚持以“我”为本，屏蔽社交媒体上的浮躁与攀比。扎实过好自己的生活，只和过去的自己比，用更好的做事方式去释怀过去，在这段艰难岁月里努力走向成熟。

## 2. 关于职业

作为新成立课题组的直博生，目前组内论文发表情况一般，也没有师兄师姐的经验可以借鉴，所以我必须对自己负责，主动出击寻找机会。

斯多葛主义中有一个很实用的技巧叫“消极想象”（Premeditatio Malorum）。在职业前景不明朗的情况下，我必须提前设想最差的境况。这并不意味着现在就要分散核心科研的精力去做多手准备，而是通过这种心理演练给自己打好预防针。这样一来，当未来真的遭遇困境时，我才不至于手足无措，依然有充足的勇气和能力去应对。

最近我也去招聘软件上摸了摸底，想看看有哪些实习机会及前置准备。我发现，如果只搜索纯“光学”岗位，机会寥寥无几；但如果放宽视野，将个人能力辐射到 AI/VLM（视觉语言大模型）、硬件等方向，选择面依然广阔，而且这些交叉领域的实习也能与实际科研工程形成互补。此外我也留意到不同企业（如京东方与华为）在薪资待遇上的显著差异，这背后反映的是不同公司对员工职能的不同定位。

经过盘点，我将自己未来可能的职业去向，按“意愿度从高到低”做了一个梳理：
1. **AI / 算法 / 大模型 / 世界模型 / VLA 工程师**（私企）
2. **光芯片 / 硅光设计 / 光学设计**（私企）
3. **相关电子 / 军工 / 光学岗位**（央国企与研究所）
4. **公务员 / 选调生**
5. **大学 / 大专教师**
6. **公私立学校教师 / 教培行业 / 健身教练**

最后一条看起来像是在开玩笑，但它确实是我深思熟虑后留作托底的“下下之策”。其实还有“创业/加入初创团队”这条路，但因风险较大且时间线不可控，暂不列入。也许未来还会涌现新的选择，只是以我当下的认知暂时无法触及。

---

没想法是一种烦恼（比如现在苦思冥想博士课题），想法太多同样是一种烦恼（比如曾经做过无数繁杂的规划）。

我的选择是：改变自己，以自身为核心，从繁芜丛杂的计划中抽离出来。把宝贵的精力全盘投入到真实的学习与实践中，让每一次复盘都变成有目的、有针对性的行动指南。绝不要再像赵括纸上谈兵那样，说起来头头是道，做起来却瞻前顾后、效率低下。
