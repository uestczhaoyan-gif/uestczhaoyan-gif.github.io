## 一个持续更新的个人空间

这个网站用于介绍我正在关注的问题，集中呈现项目，也记录学习、研究与实践中的复盘和想法。它会随着经历与兴趣一起更新。

## 内容结构

- **首页**：个人介绍、研究方向、经历与荣誉，以及手选或最近更新的项目与文章。
- **项目**：按类别浏览介绍，进入单个项目后查看背景、方法、现状与 GitHub 仓库。
- **博客**：按内容类别组织文章，保留正文目录与相关项目入口。

网站沿用 al-folio 的简洁学术主页视觉方向，使用独立编写的静态页面布局。它不是 al-folio 主题的直接安装版本。

## 如何维护

个人资料与条目索引存放在 JSON 文件中，博客与项目正文使用 Markdown。Node.js 构建脚本生成静态页面，Cloudflare Pages 在 GitHub main 分支更新后自动检查并发布正式站点；GitHub Actions 保留 GitHub Pages 备用发布。

将内容与页面模板分开，目的是让日常更新集中在写作本身。精选条目可直接调整，文章与项目可以相互链接。
