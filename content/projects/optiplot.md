## 从实验数据到科研图

OptiPlot 是面向光学实验数据的本地绘图工作台。导入数据后，先检查变量类型、缺失值、单位与重复观测，再给出候选图型及推荐理由，帮助比较同一份数据的不同表达方式。

## 当前实现

- 支持 CSV、TXT、XLSX、NPY 与部分 MAT 数据，提供光谱、偏振响应、二维扫描和器件比较等图型。
- 在桌面界面中比较预览，调整数据列映射、坐标标签、尺寸、配色与误差表达。
- 导出 PNG、SVG、PDF 等格式；可复现 ZIP 同时保存数据、参数与独立 Python 绘图脚本。
- 命令行与桌面界面使用同一套推荐和渲染逻辑，数据在本地处理，无需模型 API。

## 使用与阶段

当前仓库标记为 **0.2.0 可运行初版**，尚未发布 GitHub Release。安装依赖后运行 `python app.py`；Windows 也可使用仓库提供的启动脚本。安装与操作说明见 [项目 README](https://github.com/uestczhaoyan-gif/OptiPlot#readme)。

图型推荐反映数据是否满足绘图前提，不代表统计置信度或科学结论。单位、误差定义和数据处理选择仍由使用者确认。本页依据公开仓库整理，未在此重新运行软件验收。
